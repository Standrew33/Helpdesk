# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue: use **Report a vulnerability**
on the repository's *Security* tab. Say what you found, how to reproduce it and what it allows.

The demo site runs on free hosting. Please do not run automated scanners against it, do not try to
exhaust its storage, database or e-mail allowance, and do not use real personal data when testing.

## Supported versions

Only the latest commit on `main` is maintained.
