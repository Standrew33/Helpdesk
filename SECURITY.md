# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's **Report a vulnerability** button on the repository's *Security* tab. Say what you found, how to
reproduce it, and what you think it allows. You will get an answer within a few days.

The demo site is a portfolio project on free hosting. Please do not run automated scanners against it, do not try to
exhaust its storage or database, and do not use real personal data when testing.

## Supported versions

Only the latest commit on `main` is maintained.
